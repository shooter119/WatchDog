# 重点单位资料管理端

阶段 1 建立独立后台认证。App 扫码入口随界面整合阶段交付，完整链路验收前不要对外宣告可用。

## 初始化和恢复

在私有生产环境确认目标为已有、有效且已审批成员后执行：

```sh
docker compose exec backend node src/admin-initialize.js '<已有成员ID>'
```

只有不存在有效平台管理员时允许执行；全部平台管理员已失效时，同一命令可恢复。已有有效平台管理员时，由其登录后开通或撤销后台授权。单位 admin/manager 不会自动得到后台权限；unit_admin 还要求当前具有有效单位管理角色。

## 会话与接口

- `/admin/` 为公开登录外壳，资料和管理数据均由受保护接口提供。
- `/api/admin/login/challenges` 生成两分钟挑战，Cookie 绑定发起浏览器；`/login/claim` 一次性领取会话。
- App 认证后使用 `/api/admin-app/capability` 查询有效后台权限，`/confirm` 确认或取消；扫码凭据不得写入日志。
- 后台使用 `__Host-watchdog_admin` Secure / HttpOnly / SameSite=Strict Cookie。每请求校验有效成员与授权，空闲30分钟、绝对8小时过期。
- 写操作限定 `https://fireman119.xyz` 来源并校验 `X-CSRF-Token`。CSRF 只保存在页面内存，可通过已认证的 `/me` 恢复，不保存于 localStorage 或 URL。
- `/members`、`/grants/:memberId`、`/audit` 仅供平台管理员使用；不得撤销最后有效平台管理员。
- 成员状态、审批状态、单位和角色变化通过数据库触发器持久撤销后台会话。撤权同时取消已确认、尚未领取的挑战。
- 初始化、授权变更、确认、登录和退出进入独立审计表，不记录凭据或资料正文。

## 部署边界

后端 Docker 镜像包含 `admin/` 静态资源。正式路由将在联调阶段加入 Caddy，需精确转发 `/admin/*` 和 `/api/admin/*`，保留官网、OTA 和旧 App API。不要直接将私有附件目录配置为静态目录。

迁移 `008_admin_auth.sql` 新增后台表；`009_admin_member_revocation.sql` 新增成员变更撤销触发器。已执行迁移文件不可改写。部署前备份 PostgreSQL 与私有资料，保留旧镜像。旧代码不依赖新增表，可回切镜像；不以删表作为日常回滚方式。

当前阶段未部署、未初始化线上平台管理员，未修改版本或发布 APK。

## 阶段 2：人工资料闭环

维护人员可创建重点单位档案，按地图、预案、作战信息卡、组织架构、危险品填写条目和出处。档案与草稿均带修订号，遇到并发修改返回冲突，要求重新加载核对。发布同时校验档案与草稿修订号；发布版本固定档案快照、五类条目和引用附件，后续草稿修改不影响历史版本。平台管理员可调整维护归属，单位后台管理员只能维护所属消防单位的档案。相似名称或地址仅提示，不自动合并。

附件保存在已有持久卷 `/app/data/private-key-sites/`，不挂载公开静态目录。普通有效成员只能读取对应已发布版本引用的正式阅读附件；原始上传文件始终仅维护人员可下载，普通成员即使知道已发布版本的原件地址也不能读取。草稿、未引用附件和处理任务仅维护人员可读。PDF和DOCX生成PDF与逐页图片，原件保留；地图文件按页转换并独立切片，以图片像素坐标生成256像素瓦片，不推断地理配准；多页地图可按条目出处页码分别查看。发布确认列出完整正式阅读附件及页数，说明并非仅共享摘录页。

Docker镜像增加 `poppler-utils`、`libreoffice-writer`、`fonts-noto-cjk`。文档转换使用隔离的LibreOffice用户配置目录，不向子进程传入模型密钥和数据库凭据。含宏、可执行嵌入对象、外部模板和外部引用图片的DOCX拒绝处理；普通超链接保留。

默认限制：单文件20MiB、文档200页、图片4000万像素且单边不超过30000、全服务2个处理任务并发、每消防单位10个待处理任务、资料存储2GiB（含原件与转换结果）。单次外部转换120秒、整份任务10分钟。通过 `WATCHDOG_KEY_SITE_FILE_BYTES`、`PAGES`、`PIXELS`、`DIMENSION`、`QUOTA_BYTES`、`UNIT_PENDING`、`TIMEOUT_MS`、`TASK_TIMEOUT_MS`、`CONCURRENCY` 同名前缀环境变量可向下调整，页面展示实际限制。处理失败原因可见，人工按文件重试；进程中断后租约到期恢复，最多自动尝试3次。旧处理进程不能覆盖新租约的结果，超过24小时的无引用临时输出清理，已发布原件不删除。

阶段2新增接口 `/api/admin/key-sites` 和 `/api/key-sites`；现有 `/api/maps` 不变。停用后不能直接查阅或发布；历史警情引用的特例鉴权将在阶段4接入。阶段2保留历史版本，尚不表示警情关联已验收。

本地验收包括150家合成单位检索分页、真实PDF/DOCX转换、图片切片、HTTP上传到发布闭环、草稿/归属/版本/附件隔离、任务恢复与配额限制。浏览器使用隔离测试库中的合成成员演练，不替代Android手机扫码与真实资料试点。

## 阶段 3：AI辅助整理

后台对已转换附件明确选择页码后发起AI任务。默认每批最多20页，长文档可选择不同页码分批处理，不静默截取前几页。默认全服务1个AI任务并发，每个成员每分钟最多3次新建/重试请求，计数持久化；任务请求与归属、授权均由服务端检查。`KEY_SITE_AI_MODEL` 单独指定资料模型，默认沿用 `DEEPSEEK_CHAT_MODEL` 或 `deepseek-flash`，密钥仅从服务端配置读取。只向既有模型主机允许列表中的HTTPS地址发送选定页的预览图片，不启用搜索或执行资料内指令；转换子进程不获得模型密钥。

AI结果单独保存于任务中，保留逐页原文、分类建议、来源、缺失提示、冲突和失败原因。字段须有对应原文证据，无法核实的联系人、数量等字段留空待核对，地图不生成地理配准。单份原件可被多个资料模块显式引用，但仍严格校验单位、版本和页码；地图条目必须引用已完成对应页切片的原件。

网页逐页并排展示原件和建议，支持放大、人工修订标题及字段、调整分类。只有勾选人工核对并明确采用的条目才追加到人工草稿，不能替换已有条目；采用同时校验草稿修订号、任务代次和重复采用，服务器固定真实来源。发布还需独立确认全平台共享。AI成功或重试本身不触发草稿更新或发布。

任务进度逐页落库，重试仅处理所选失败页面，保留成功页、已采用记录和人工草稿。过期租约恢复，三次中断后明确部分失败/失败；旧worker、取消后的迟到结果不能写回。后续页发送前重新检查提交者授权和维护归属，当前维护人员可显式重试接管。默认每次AI请求90秒、整份任务20分钟、持久化结果2MiB；可通过 `WATCHDOG_KEY_SITE_AI_PAGES`、`AI_CONCURRENCY`、`AI_REQUEST_TIMEOUT_MS`、`AI_TASK_TIMEOUT_MS`、`AI_RESULT_BYTES`（均加同名前缀）向下调整。无模型配置时保留完整人工流程。

新增 `/api/admin/key-sites/:id/attachments/:attachmentId/ai`，以及 `/api/admin/key-sites/tasks/:taskId` 的查询、`ai-retry`、`ai-cancel`、`ai-apply`。均使用后台Cookie与写操作CSRF，不接受普通App会话。目录接口仅返回任务进度摘要，识别正文需逐任务鉴权读取。审计不记录资料正文或凭据。

已用合成图片完成真实模型HTTP 200探针，识别数量与位置并保留页码出处；该证据不代替真实资料试点。自动化覆盖字段证据、冲突保留、部分成功、失败页重试、人工修订保护、撤权停止发送、取消/租约隔离、大小上限和HTTP权限边界。
