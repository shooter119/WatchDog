# 火场智控

一款由消防员开发、给消防员用的 App，火场安全管控的消防救援智能体。

## 为什么会有这个 App

火场里，每个岗位都在和时间、信息与风险打交道。安全员要盯着人员和气瓶，指挥员要掌握现场变化，进入火场的消防员也需要及时了解自己的状态和队友的动态。信息一多、节奏一快，任何人都可能没有时间记录、核对或查找资料。

但现场往往是这样：防护服、手套、对讲机的嘈杂声，烟雾里看不清纸笔，指挥员一句「报一下里面几个人」，靠的是一张被水打湿的名单和一个记在心里的时间。气瓶剩余时间要心算，人多了一乱就错。我们太清楚那种手忙脚乱的感觉了。

我们最初是为了解决安全员没有时间记笔记的问题，后来逐步扩展为给火场上不同岗位的消防员提供一些力所能及的帮助：减少重复记录，及时提醒关键状态，留下清晰的现场过程，并在需要时提供快速、可靠的辅助信息。

所以这个 App 从头到尾只坚持一件事：**让现场人员少分一点心，把注意力留给真正需要判断和处置的事情**。

## 它是怎么用的

安全员站在入口，队员进场时报一句「张三，24」：

- App 自动听清人名和压力值，算好这瓶气还能用多久
- 谁进来、谁出去、还剩多少分钟，看板上实时滚动
- 快没气了，App 会先说话提醒，再响警报
- 退场时一句「张三退场」，记录自动归档

全程不用敲一个字，戴着战术手套也按得动。底部就五个入口：**日志、看板、语音、辅助、设置**。中间那个橙色的麦克风，就是安全员最快的那只手——按住说话，文字会边说边出现，松手后快速定稿；单次录音最长 60 秒，接近上限会提示，时间到自动结束并继续处理已录内容。云端连接异常时保留录音并自动切换本机识别。

多台设备加入同一场警情档案后，指挥员和多个安全员看到的是同一块看板，数据实时同步；处置结束后档案自动归档，名称和完整火场时间线都可在设置中复盘。

## 它能帮你什么

- **语音录入**：进场、退场、压力值，一句话搞定；支持边说边返回文字，松手后再进行一次业务解析；多人进场一次报完一次确认，每个人的气瓶容量还能单独改；单次录音最长 60 秒，最后 10 秒提示，到点自动处理已录内容，云端失败自动回退本机 ASR
- **自动计算**：气瓶容量、压力、消耗率交给我们算，剩余 10 分钟提醒、5 分钟报警
- **实时看板**：在场谁、进去多久、还剩多久，一目了然；到点自动播报、响警报，锁屏也推通知
- **火场日志**：进场自动记录为「张三进入救援现场，空气呼吸器压力24兆帕」，撤离自动记录为「张三撤离救援现场」；其他现场信息也可语音记入，按实战环节分类（部署/搜救/出水/撤离/异常），回头好复盘
- **辅助问答**：火场智囊「水元素」——浓烟里拿不准主意，按住说话问一句，语音转写仅作为辅助页与 AI 交流的文字，不会发布到火场日志；默认联网检索，遇到陌生危险化学品等问题可查找最新资料，再按「结论、立即行动、注意事项」简洁给出建议。支持拍照或从相册选择单张图片进行消防视觉辅助分析，清晰的危化品运输标牌 UN 编号会自动联网查询对应物质及来源，模糊编号需补拍确认，图片临时上传至服务端和 DeepSeek-V4.1-Flash，默认不保存原图；收到整段警情简报时会主动研判风险、处置要点和待核实信息，不必再追问“想了解什么”；对话历史只保存在本机，不关联警情、不参与多人协同
- **单位语音词库**：完成单位认证后自动加载本单位预置姓名、专业词汇和成员新增词条；所有已认证用户都可直接补充词条，词库同时注入云端与本机识别；退出单位后本机自动清空该单位词库
- **数据统计**：每人的进出场次数、时长一清二楚，训练复盘心里有数
- **断网可用**：语音识别与语义解析都能在本机运行（本地 ASR 主模型约 75MB，另有可选的 9.8MB 降噪模型）；模型下载和缓存启用前会按部署清单校验大小与 SHA-256，低存储时不会自动删除当前模型或现场数据，可清理空间后重试或继续联网识别，火场没信号照样录
- **版本更新**：正式版本会经过自动构建和完整性校验，用户可以在 App 内获取更新并安全安装
- **多设备登录与冲突核对**：同一成员可同时使用多台设备，新登录不会踢掉旧设备；在「设置 → 用户操作 → 登录设备」查看最近活动并退出指定设备或其他设备。人员压力、编辑和出场采用版本校验，重复进场不能绕过检查；离线冲突保留在「离线记录待核对」，由原成员核对、保留或重新确认提交，旧读数不会自动覆盖新状态。旧队列缺少身份时需人工确认原记录归属。后端写入门禁默认关闭；App 1.10.0 发布后先保持兼容模式，待两台实体设备完成并行登录、并发写入、断网补传和设备撤销验收，再启用 `WATCHDOG_ENTRY_VERSION_REQUIRED=1`。启用后旧版仍可读取，缺少版本的关键写入明确要求升级。
- **用户认证与游客模式**：首次打开支持一键开启游客模式（无需登录即可单机体验空呼测算、本地语音与随手记），顶部常驻横幅支持随时转正，首页与设置页连接状态明确标识单机；正式加入支持双轨制——队员凭单位码自主申请加入（本单位站长、单位管理员或有平台管理员授权的本单位成员在 App「设置 → 入队审批」处理后即可登录；多名管理员共享待办，在线同步更新并每30秒校准，失败可重试，已处理记录保留处理人与时间，不包含离线系统推送）或由管理员直接手动录入；审批通过或录入后姓名自动秒级同步至单位 ASR 热词与离线词库；语音名单只用于提升识别准确率、不授予登录权限，登录失败会区分“已在语音名单但尚未开通登录”与“姓名写法对不上”并给出近似姓名候选；认证后支持统一警情列表——可选择正在处置的现场、直接认领衢州近3天官方派警一键建档（自动带入编号、地址、分类、现场描述、报警人联系方式、调度力量规模及高精度经纬度），或手动新建带时间戳名称的警情，亦可暂不选择警情直接进入 App；列表清晰区分【自建】与【官方待认领/处置中】，支持按地址或类型搜索与手动刷新；同一官方警情首位队员认领建档后，队友点击自动加入同一档案；未选警情时首页警情名称显示“暂无正在处置的警情”，日志、看板和语音登记会引导先选择或新建，其他功能可按需使用；活跃使用期间会话自动滑动续期，长时间未使用或达到绝对期限后回到认证界面，并保留单位名称和姓名供快速重登；测试与 CI 使用仓库内的假名示例组织；生产环境必须通过私有种子文件或环境变量导入本单位名单、消防站和验证码，源码不再内置真实单位信息，也不会改写已有警情的单位归属；未完成认证前底部导航与语音入口会被锁定；警情名称、参战消防站、车辆和人员数量可协同维护
- **全局号码一键呼叫**：App 内全局（警情详情、现场火场随手记等）文本中出现的手机号与固定电话自动识别，采用零抖动内联高亮并附带呼叫提示；点击直接唤起系统拨号盘，长按可复制号码，确保火场关键联络秒级直达
- **首页警情卡**：默认折叠，仅显示警情名称、类别和队伍数量；点击展开后可登记力量、信息导入、调整灾情等级、查看详情及归档，减少对处置区域的占用。
- **警情信息导入**：从统一“信息导入”入口选择拍照、从手机相册多选或粘贴文字通报；先核对建议名称、地点、类型和出动力量，再统一应用。每批最多9张图片，支持逐页进度、失败页重试和未完成任务恢复；未提供的车数、人数显示“待补充”，不会自动生成个人进场或计时记录。提取依赖当前配置的云端AI，需人工核对
- **单位常用队伍**：名录外队伍也能登记、编辑，可选择保存到本单位常用队伍；成员可新增，管理员维护已有名称、别名及停用状态；历史现场名称保持不变
- **警情资料与辅助背景**：资料和导入文字随警情保存、同步、归档；辅助问答自动使用已确认资料，对话按单位和警情隔离，旧版对话在“历史通用对话”查看。临时原图最长保留24小时，应用、取消或到期后清理；正式档案保存提取文字而非原图
- **自动归档**：连续 12 小时没有现场业务活动自动归档；归档页按时间查看档案、参战力量快照和晚到早的完整事件时间线
- **离线补传**：已加入警情后，进退场、压力复核和随手记会持久化暂存，恢复网络后按发生顺序幂等补传
- **后台诊断**：App 捕获 Flutter/Dart 未处理异常后写入本地滚动日志，联网且已加入警情时自动脱敏补传，便于分析红屏和插件异常，不增加操作界面
- **地图兼容**：保留旧客户端 `/api/maps` 的鉴权与正射影像接口；新版从首页「重点单位」按资料版本查看地图，不再提供设置页地图入口。演示影像明确标识，图片坐标不提供经纬度定位。旧图导入方法见 [地图部署说明](deploy/maps/README.md)
- **视频资源与系统画中画**：首页「现场工具 → 视频资源」可查看本单位授权监控；播放后在 App 内提供行内、全屏与浮动三种呈现共识同一路会话。播放期间切到后台或其它 App，画面以系统画中画（Android 8.0+，无额外悬浮窗权限）继续可见，App 恢复前台后回到原页面；回到前台会重新挂载渲染目标，避免长时间后台后画面停在最后一帧。分屏/画中画下只渲染视频画面，不显示导航与其它界面元素；不支持画中画的设备会自动退化为普通后台行为
- **重点单位资料后台**：授权成员在[管理后台](https://fireman119.xyz/admin/)按既有基本情况范例直接填写标准分项表单：单位概况、毗邻道路、生产装置、消防设施及水源、工艺流程、重点提示、仓库库存、储罐和联系人；地图与 360° 全景、应急预案及危化品速查库按独立模块维护。支持为单个重点单位上传单张或多张 2:1 等距圆柱投影（equirectangular）360° 全景图（兼容 8K/14K 航拍全景自动压制）并通过自建 Pannellum 2.5.7 引擎进行多机位漫游预览。无需上传原件、填写信息出处或经过 AI 整理。保存仅更新草稿，点击「发布到 App」后全平台已认证有效成员可查阅，游客不可访问；草稿与发布仍保留并发修订检查及历史版本。地图文件为选填，关联处理完成的地图及页码后，App 可从「查看地图」打开。App 按分项字段展示已发布信息，不展示出处；首页「现场工具 → 重点单位」进入，设置身份卡可扫码确认后台登录，单位角色不代表后台权限。历史版本和后台审计继续保留。部署说明见[管理端说明](deploy/vps/ADMIN.md)与[VPS说明](deploy/vps/README.md)。
- **标准化单位资料**：参照单位基本情况表，提供单位概况、毗邻与道路、生产装置、消防设施及水源、工艺流程、重点提示、仓库库存、储罐、联系人九类标准记录，归入现有五类页面。每套装置、每种存货及每个储罐独立维护；设计容积、包装储量与实际储量分开，原文单位、约数、空白及涉密说明不推断。后台手工录入和AI核对共用字段定义，兼容原有通用资料及历史发布版本。字段与录入约定见 [标准说明](deploy/vps/KEY-SITE-STANDARD.md)
- **视频资源**：首页新增“视频资源”入口，本单位已认证成员可查看管理员启用的监控与现场画面；资源名称旁实时显示可用状态，绿色表示地址可达，红色表示探测失败。管理员在设置页维护资源名称、说明、HTTP-FLV 地址和启用状态，普通成员不可见管理入口。点击资源后卡片就地竖屏展开并立即播放；播放器角上的图标可切到自动横屏的全屏模式，或回到首页以竖屏浮窗继续播放，小窗内也能再次切回全屏。三种视图复用同一路连接，关闭按钮会停止播放并收起卡片或关闭窗口。首次建流保留加载态，非致命播放器噪声和短暂错误不会抢先显示失败；App 使用现有 media_kit 播放器，不转 HLS、不中转，断线后自动重试，视频地址只存数据库，不写入公开源码。
- **水印相机**：可在「水印设置」中选择横屏完整视野或竖屏 16:9 中心裁切，默认横屏，两种模式成片均为横版 16:9；拍摄现场照片与小视频时，把单位、地址、天气、拍摄人和精确到秒的时间直接烧进画面；单段视频最长 60 秒。相机权限被拒后可进入系统设置恢复授权，返回后重新检查权限。核对页只保留「保存并分享」和「仅保存」：两者都会把同一拍摄的带水印版与无水印版成对保存到手机相册，任一份失败就整体回滚；「保存并分享」在成对保存成功后只分享带水印文件，不附带口述文字。App 内的拍摄文件仅作为核对期间的工作副本，保存成功后会在后台清理，手机相册成为唯一保存位置；清理进度不会阻塞返回相机，进程中断后下次启动继续处理。改造前的历史资料没有母版，只能保存带水印版并明确提示。照片与视频不上传；开启联网识别时仅上传提取的音频进行转写，失败时回退本机识别，核对后可选写入警情，写入操作与相册保存相互独立
- **定位分享**：首页「现场工具」在空闲和现场监控状态下常驻展示。定位分享会展示当前警情、单位、地址、定位时间、精度和 WGS84 坐标，可复制完整文案或调用系统分享发送纯文本；文案同时附带“查看位置”和“驾车导航”两个独立成行的高德 HTTPS 链接。后端先把 WGS84 转为 GCJ-02 再查询地址和生成驾车路线，减少高德导航偏移；坐标转换失败时仍保留 WGS84 查看位置并隐藏驾车导航。微信内验收目标是链接能打开高德 H5 位置或路线页，不承诺直接唤起高德 App，也不使用微信 OpenSDK、公众号 JS-SDK 或小程序。定位权限被拒、系统定位关闭、精度差或定位过期均有明确提示和恢复入口；超过 2 分钟提示核实，超过 5 分钟禁止直接分享并要求重新定位。位置只用于本次分享，不保存历史、不包含发送人姓名，也不上传接收方信息
- **路况查询**：首页「现场工具 → 路况查询」根据当前警情的事发地点与本机定位，由服务端代理调用高德地理编码、驾车路径规划和天气接口，展示赶赴现场的预计耗时、行驶里程、红绿灯数量、实时路况分段占比与拥堵/缓行路段提醒、主要途经道路及分段指引，并同步展示事发地实时天气、风向风力与当日昼夜天气趋势，支持多备选路线切换、复制路况简报和打开高德导航；官方警情优先直达高精度经纬度，跳过口述地址文本逆地理编码与歧义匹配；若未选警情或警情缺少具体位置信息，会引导先完善警情资料或导入警情信息；本机定位不可用时仍降级展示事发地天气与终点导航
- **危化速查**：首页「现场工具 → 危化速查」内置 65+ 种常见危化品离线种子库并持久化至本地 SQLite，断网状态下输入 4 位 UN 编号（支持带或不带 UN 前缀）、中文品名或常见俗名即可秒出高对比度「电台战术复诵卡」，按遇水属性（严禁用水 / 慎用剧烈反应 / 可用水控制）、绝对禁忌、推荐灭火与防护等级、初期隔离疏散距离及折叠理化急救参数分级呈现，并支持一键复制纯文本处置要点粘贴至救援调度群；联网认证后后台静默增量同步单位云端标准库及软删除记录；本地未命中时不会自动联网扣费，可手动点击「AI 应急提炼战术卡」优先匹配云端标准库、再由 AI 辅助提炼并附带显著核实警示，无法核实时诚实提示不编造
- **火场友好**：屏幕常亮、后台保活、按键式录音，戴着手套、满场嘈杂也能用；内置「昼白」「暖砂」「夜间战术」三套配色，可在设置中即时切换（仅存本机，不同步服务器）

## 全局不变量 (Global Invariants)

1. `[safety:air-first]`：空呼可用时间倒计时与现场监控具有最高实时性优先级，严禁因网络同步阻塞或 ASR 异常影响本地秒级告警。
2. `[safety:dual-mode-resilience]`：全系统严格遵循「云端增强、断网可用」设计。在完全无网络环境下，端侧离线 ASR、本地规则解析与 SQLite 队列保障核心进退场与空呼测算完全自治。
3. `[security:data-anonymization]`：源码库、测试用例与公开说明严格脱敏，严禁出现真实消防队伍名称、人名、真实地址或生产凭证。
4. `[quality:strict-gates]`：全工程坚守「绿色交接」原则，发版执行严格 fail 0 门禁（后端 322/322 单测全过，App 471/471 测试全过 + analyze 0 警告）。

## 全局副作用 (Global Side Effects)

- 后端维护 PostgreSQL 17 物理持久化与长连接 WebSocket 广播。
- 移动端申请系统音频焦点、前台常驻服务、锁屏通知与硬件常亮。
- 生产环境自动化脚本向异地灾备拉取增量快照并执行哈希双向校验。
